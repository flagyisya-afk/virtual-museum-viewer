Valentine's Hidden World

Open `v2/index.html` in a browser (or run a simple static server) and explore:

- Click hearts to reveal messages.
- Find all hearts to trigger the celebration.

Run a local server (recommended):

```bash
# from the workspace root
python -m http.server 8000
# then open http://localhost:8000/v2/
```
